## Projects & Experiments

### Optimization Algorithms

Adam의 갱신 규칙과 유효 보폭을 분석하고, 회전을 고려한 최적화 방법을 탐색했습니다.

- Rosenbrock와 rotated quadratic에서 Adam 및 변형 방법 비교
- 학습률과 초기 조건에 따른 목적함수 값과 수렴 과정 관찰
- 여러 seed와 목표값 도달 시간을 활용한 실험 결과 검토
- 수학적 의도와 실제 구현 사이의 차이 분석

### VLCC Ship Design

조선해양공학의 졸업 팀 프로젝트에서 **32만 DWT급 VLCC의 선박 설계 부문**을 담당했습니다.

- 주요 제원 결정 및 부품·장비의 개략 사양 선정
- 중량, 요구 부피, 건현 제약을 고려한 설계 조건 검토
- 엔진·프로펠러 성능과 건조 비용을 고려한 설계 대안 탐색
- 선체·탱크 구획 설계 스크립트와 적재 계산 오류 검토

### Autonomous Vessel Localization

IMU와 2D LiDAR를 활용한 자율운항 선박의 위치·속도 추정 방법을 검토했습니다.

- LiDAR odometry와 관성 센서 결합 방식 학습
- Python과 시리얼 통신을 이용한 IMU 데이터 수집 검토
- 선박의 선회 응답과 제어 지연을 고려한 장애물 회피 방식 탐색

### Furniture Design Tool

웹 기반 책장 설계 도구를 책상·싱크대 설계로 확장하는 작업을 진행했습니다.

- 치수와 부품 배치를 조정하는 설계 기능
- 판재 조건과 결합 방식을 반영한 부품 구성
- 현장 활용을 고려한 원장 재단 배치와 소요 장수 검토
